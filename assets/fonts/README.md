Local fonts preserve the site's original Manrope and Barlow Condensed typography.

Font sources: Google Fonts CSS for Manrope (400, 600, 700, 800) and Barlow Condensed (600, 700, 800). Delivery files are WOFF2 converted from the downloaded TTFs without changing font outlines. `fonts.css` uses `font-display: swap`.

Licenses are included in LICENSE-manrope.txt and LICENSE-barlowcondensed.txt.
